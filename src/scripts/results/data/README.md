# Data

This directory contains the datasets and processed feature representations used in the TLH-AFP experiments.

## Datasets

- AntiFP: primary dataset for model development and independent evaluation.
- DeepAFP-Main: independent external dataset for generalization evaluation.

Due to dataset size and repository limitations, large binary feature files are not included directly in the repository.

Please refer to the main manuscript and the original dataset publications for dataset sources and usage information.
